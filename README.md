# Amal Soft Solutions — React Website

## Requirements
- Node.js 20.19+ or 22.12+ recommended

## Run locally
```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Logo
The exact supplied logo is in `public/amalsoft-logo.png`. Keep this filename, or update the `src` in `ASLogoEmblem` inside `src/App.jsx`.

## Notes
- The app is configured for React + Vite + Tailwind CSS + lucide-react.
- The intro animation timing has been fixed so stage changes no longer restart the animation timer.
- The intro uses the original logo image asset rather than a hand-drawn substitute.
